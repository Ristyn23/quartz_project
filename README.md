# Quartz Analysis Plugin for Fiji/ImageJ

Плагин для среды Fiji/ImageJ2, предназначенный для полуавтоматического морфометрического анализа микроструктур кварца. Решение реализует конвейер обработки изображений: от сегментации границ зерен с использованием классификатора Weka до водораздельного преобразования (watershed), ручной коррекции меток и экспорта геометрических характеристик в формат CSV.

## Системные требования

Для сборки и корректной работы проекта строго соблюдаются следующие зависимости:

* **JDK 11** (рекомендуется Oracle OpenJDK 11.0.x или аналог). Использование JDK 17 и выше приведет к ошибкам совместимости на уровне модульной системы и библиотек SciJava/ImageJ2.
* **Apache Maven** 3.6+ (для управления зависимостями и сборкой).
* **Fiji (ImageJ)** актуальной версии (для развертывания скомпилированного артефакта).

## Сборка и развертывание

1. Клонирование репозитория:

   ```bash
   git clone https://github.com/Ristyn23/quartz_project.git
   cd quartz_project
   ```
2. Сборка проекта:

   ```bash
   mvn clean package
   ```

   В результате в директории `target/` будет сформирован файл `quartz_project-1.0-SNAPSHOT.jar`.
3. Развертывание в Fiji:
   Скопируйте полученный `.jar`-файл в директорию `plugins/` вашей локальной установки Fiji.

## Порядок использования

1. Запустите Fiji.
2. В главном меню перейдите по пути: `Plugins > Quartz > Analyze Quartz`.
3. В открывшемся интерфейсе загрузите исходное изображение (поддерживаются форматы BMP, PNG, TIFF, JPEG) и предварительно обученную модель Weka (`.model`).
4. Нажмите кнопку **Обработать**. Система выполнит сегментацию границ и построит начальную карту меток зерен.
5. При необходимости используйте инструменты **Объединить** или **Разделить линией** для ручной коррекции артефактов автоматической сегментации.
6. Нажмите **Сохранить CSV...** для экспорта таблицы морфометрических данных (площадь, периметр, эквивалентный диаметр, оси эллипса, коэффициенты формы).

## Архитектурные особенности

Проект реализует адаптированный паттерн MVC в рамках экосистемы SciJava:

* **`istu.quartz.commands`**: точки входа, регистрируемые через аннотацию `@Plugin`. Отвечают за инъекцию зависимостей и инициализацию UI.
* **`istu.quartz.model`**: ядро бизнес-логики, изолированное от фреймворка отображения. Содержит алгоритмы сегментации `GrainBoundarySegmenter`, водораздельного преобразования `GrainWatershed`, управления картой меток `GrainLabelMap` и расчета метрик `GrainMeasurement`.
* **`istu.quartz.ui`**: реализация пользовательского интерфейса на базе Swing. Тяжелые вычисления вынесены в `SwingWorker` для предотвращения блокировки Event Dispatch Thread (EDT).

## Технические ограничения

1. Алгоритм сегментации ожидает на входе одиночное 2D-изображение в цветовом пространстве RGB (`ImagePlus.COLOR_RGB`). Работа со стеками (Z-stack) или 16-битными изображениями в текущей версии не поддерживается.
2. Файл модели `.model` должен содержать класс с точным именем `grain_boundary`. Отсутствие данного класса приведет к исключению `IllegalArgumentException` на этапе инициализации сегментатора.
3. Операции ручного разделения (`split`) и объединения (`merge`) зерен выполняются на уровне пиксельных массивов. Для изображений сверхвысокого разрешения (>4000x4000 px) возможна задержка отклика интерфейса.
