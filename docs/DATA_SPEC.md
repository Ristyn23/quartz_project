## Назначение

Плагин Quartz Analysis предназначен для полуавтоматического морфометрического анализа микроструктурных изображений кварца. Решение выполняет сегментацию границ зёрен, разделяет слипшиеся объекты, позволяет вручную корректировать результаты автоматической обработки и экспортирует геометрические характеристики каждого зерна в формат CSV для дальнейшего статистического анализа.

Документ описывает порядок подготовки входных данных, установки плагина, выполнения анализа и устранения типичных ошибок. Техническое устройство системы изложено в документе [ARCHITECTURE.md](ARCHITECTURE.md).

## Требования к входным данным

### Исходное изображение

Перед запуском анализа убедитесь, что изображение соответствует следующим требованиям:

| Параметр | Требование |
|----------|------------|
| Формат файла | BMP, PNG, TIFF, JPEG |
| Цветовое пространство | RGB (24-бит) |
| Структура | Одиночное 2D-изображение (без Z-стека) |
| Разрешение | Рекомендуется не менее 1024×1024 px для надёжной сегментации |

Ограничения:
* Изображения в оттенках серого (8-бит), 16-битные и многоканальные (CFA, гиперспектральные) форматы не поддерживаются.
* Стек изображений (Z-stack) обрабатывается как ошибка валидации. При необходимости анализа нескольких срезов обрабатывайте каждый срез как отдельный файл.

### Модель классификатора Weka

Для сегментации границ требуется предварительно обученная модель, сохранённая в формате `.model`. Модель должна быть обучена в модуле Trainable Weka Segmentation среды Fiji.

Обязательное требование: в модели должен присутствовать класс с точным именем `grain_boundary` (без кавычек, с символом подчёркивания). Отсутствие данного класса приведёт к ошибке на этапе применения классификатора.

Рекомендуется обучать модель на репрезентативной выборке изображений, аналогичных анализируемым по увеличению, освещению и контрасту.

## Установка плагина

1. Соберите артефакт проекта командой:
   ```bash
   mvn clean package
   ```
2. Скопируйте файл `target/quartz_project-1.0-SNAPSHOT.jar` в директорию `plugins/` вашей локальной установки Fiji.
3. Перезапустите среду Fiji. Плагин появится в меню: `Plugins › Quartz › Analyze Quartz`.

Для проверки корректности установки выполните команду `Plugins › Quartz › Hello Quartz`. В консоль Fiji должно быть выведено сообщение `Hello from Quartz plugin!`.

## Порядок выполнения анализа

### Шаг 1. Запуск интерфейса

Откройте Fiji и выберите в главном меню:

```
Plugins › Quartz › Analyze Quartz
```

Будет открыто главное окно плагина, содержащее три вкладки: Снимок, Карта границ, Зёрна.

### Шаг 2. Загрузка входных данных

Загрузить файлы можно одним из двух способов:

Способ А. Через кнопки интерфейса:
* Нажмите Открыть изображение и выберите файл снимка.
* Нажмите Выбрать модель и укажите путь к файлу `.model`.

Способ Б. Перетаскиванием (Drag-and-Drop):
Перетащите файлы изображения и модели непосредственно в окно плагина. Допускается одновременное перетаскивание обоих файлов.

После успешной загрузки в нижней части окна отобразится название изображения и его разрешение, а рядом с кнопкой выбора модели — имя файла модели.

### Шаг 3. Запуск обработки

Убедитесь, что оба файла загружены, и нажмите кнопку Обработать в правой части панели инструментов.

Процесс выполняется в два этапа:
1. Сегментация границ. Классификатор Weka применяется к изображению и формирует карту вероятностей принадлежности каждого пикселя к классу `grain_boundary`.
2. Водораздельное преобразование. Карта вероятностей сглаживается гауссовым фильтром, квантуется и передаётся алгоритму watershed (MorphoLibJ) для разделения слипшихся зёрен и присвоения уникальных идентификаторов.

Во время выполнения интерфейс остаётся отзывчивым. По завершении первого этапа автоматически активируется вкладка Карта границ, по завершении второго — вкладка Зёрна.

### Шаг 4. Ручная коррекция результатов

Автоматическая сегментация может содержать артефакты: недостаточно разделённые зёрна или, наоборот, ложные границы. Для их устранения предназначен интерактивный редактор на вкладке Зёрна.

Подробное описание инструментов коррекции приведено в разделе [Инструменты ручной коррекции](#инструменты-ручной-коррекции).

### Шаг 5. Экспорт данных

После завершения коррекции нажмите Сохранить CSV…, укажите путь и имя файла. По умолчанию предлагается имя `measurements.csv`. Если файл с таким именем уже существует, будет запрошено подтверждение на перезапись.

Формат выходного файла описан в разделе [Формат выходных данных](#формат-выходных-данных).

## Инструменты ручной коррекции

На вкладке Зёрна доступны следующие операции:

### Выделение зёрен

Кликните левой кнопкой мыши по зерну на изображении. Выбранное зерно подсвечивается оранжевым цветом, его граница отображается более насыщенным оттенком. Под изображением отображаются морфометрические характеристики выбранного зерна: площадь, вытянутость, круглость.

Для снятия выделения кликните по фону (вне зерна).

### Объединение зёрен

Инструмент Объединить предназначен для слияния двух соседних зёрен, ошибочно разделённых алгоритмом watershed.

Порядок действий:
1. Убедитесь, что кнопка Разделить линией не активна.
2. Кликните по первому зерну — оно будет выделено.
3. Кликните по второму зерну — будут выделены оба.
4. Нажмите Объединить. Зёрна будут объединены в одно с сохранением идентификатора первого выбранного зерна.

Объединение возможно только для зёрен, имеющих общую границу. При попытке объединить несоседние зёрна в нижней панели появится сообщение: *«Выбранные зёрна не соседствуют. Выберите другую пару.»*

### Разделение линией

Инструмент Разделить линией предназначен для разделения одного зерна, ошибочно объединённого алгоритмом watershed с соседним.

Порядок действий:
1. Нажмите кнопку Разделить линией — она перейдёт в активное состояние.
2. Кликните по зерну, которое необходимо разделить. Зерно будет выделено.
3. Зажмите левую кнопку мыши и проведите линию от одного края зерна до другого. Линия должна пересекать зерно полностью, начиная и заканчиваясь на его границе.
4. Отпустите кнопку мыши. Зерно будет разделено на две части.

Правила разделения:
* Линия должна делить зерно ровно на две связные области. Если линия не пересекает зерно полностью или разделяет его на три и более частей, операция будет отклонена.
* Меньшая из полученных частей получит новый идентификатор, большая сохранит исходный.
* После успешного разделения инструмент автоматически деактивируется.

### Масштабирование и навигация

* Масштабирование: вращение колеса мыши с центром в позиции курсора.
* Сброс масштаба: прокрутка до минимального уровня.

## Совмещение нескольких снимков

Для анализа больших областей образца, не помещающихся в одно поле зрения микроскопа, плагин предоставляет отдельное окно совмещения перекрывающихся снимков.

### Запуск окна совмещения

Откройте Fiji и выберите в главном меню:

```
Plugins › Quartz Segmentation › Merge Images…
```

Будет открыто окно Quartz Segmentation — Объединить снимки, содержащее список кадров, панель управления и три вкладки: Исходные кадры, Проверка совмещения, Объединённый снимок.

### Подготовка кадров

Все кадры должны удовлетворять следующим требованиям:
* Одиночные RGB-снимки одинакового размера.
* Частичное перекрытие между последовательными кадрами (рекомендуется 30–50%).
* Одинаковый физический масштаб (при наличии калибровки).
* Первый кадр в списке является опорным — к его системе координат приводятся все остальные.

Кадры добавляются кнопкой Добавить снимки… (допускается множественный выбор) либо перетаскиванием файлов в окно. Порядок кадров можно изменять кнопками Выше / Ниже, удалять — кнопкой Удалить.

### Выполнение регистрации

Нажмите кнопку Совместить. Алгоритм выполнит следующие шаги:
1. Извлечение признаков SIFT на каждом кадре.
2. Сопоставление признаков между последовательными кадрами.
3. Фильтрация выбросов через RANSAC.
4. Накопление rigid-трансформаций относительно опорного кадра.
5. Рендеринг всех кадров на общий холст.

Во время выполнения в нижней части окна отображается прогресс. По завершении автоматически активируется вкладка Проверка совмещения.

### Проверка качества совмещения

На вкладке Проверка совмещения отображается наложение первого кадра и выбранного в списке. Слайдер прозрачности позволяет плавно переключаться между кадрами и оценить точность регистрации. Под изображением выводится описание трансформации текущего кадра: угол поворота, величина сдвига, количество совпавших признаков.

При неудовлетворительном результате:
* Проверьте порядок кадров в списке.
* Убедитесь, что на всех кадрах изображена одна и та же область образца.
* Удалите кадры с существенными артефактами (блики, расфокусировка) и повторите совмещение.

### Усреднение и сохранение результата

Нажмите Объединить для усреднения RGB-каналов по всем кадрам с учётом реального покрытия каждого пикселя (coverage-aware averaging). Результат появится на вкладке Объединённый снимок.

Дальнейшие действия:
* Сохранить TIFF… — сохранить объединённый снимок в файл.
* Использовать в Quartz — передать результат непосредственно в основное окно анализа без промежуточного сохранения.

## Задание физического масштаба

Для получения морфометрических характеристик в физических единицах (мкм, мм и т.д.) необходимо задать физический масштаб изображения.

### Калибровка по двум точкам

1. В основном окне анализа или в окне совмещения снимков найдите панель Масштаб.
2. Нажмите Задать по двум точкам….
3. Курсор примет вид креста. Кликните по первому концу отрезка известной длины на изображении.
4. Кликните по второму концу отрезка.
5. В открывшемся диалоге введите реальное расстояние и выберите единицу измерения (мкм, мм, см, м) либо введите произвольную.
6. Нажмите OK.

На изображении появится линейка масштаба (scale bar). Текущий масштаб отображается в панели Масштаб в формате `1 px = X unit`.

### Отмена и сброс

* Esc — отменить текущий выбор точек.
* Сбросить масштаб — удалить калибровку и вернуться к пиксельным единицам.

### Сохранение масштаба

Физический масштаб сохраняется автоматически:
* В TIFF-файле разметки — через метаданные `Calibration` ImageJ и маркер `[Quartz scale]` в поле `Info`.
* В ROI ZIP-архиве — через файл `quartz.properties` внутри архива.
* В объединённом снимке — масштаб берётся из первого (опорного) кадра.

При загрузке файла масштаб восстанавливается автоматически.

### Влияние на экспорт

При заданном масштабе в CSV-файл дополнительно записываются калиброванные метрики: `length_unit`, `pixel_size`, `area_calibrated`, `perimeter_calibrated`, `equivalent_diameter_calibrated`, `major_axis_calibrated`, `minor_axis_calibrated`. Базовые пиксельные метрики сохраняются без изменений.

Подробное описание калиброванных колонок приведено в документе [DATA_SPEC.md](DATA_SPEC.md).

## Ограничение области анализа

Плагин поддерживает анализ только части изображения через маску области анализа. Маска встраивается в TIFF-файл как Base64-кодированный PNG в поле `Info` и не требует дополнительных файлов.

### Применение маски

Если TIFF-файл содержит встроенную маску области, она автоматически применяется при загрузке изображения. Вне маски:
* Алгоритм watershed не создаёт зёрен.
* Инструменты ручной коррекции не затрагивают пиксели.
* На превью маска отображается как шахматный паттерн.

### Создание маски через выделение области

Маска области создаётся автоматически при кадрировании объединённого снимка в окне совмещения (см. раздел [Выделение области интереса](#выделение-области-интереса)).

## Сохранение и загрузка разметки

Промежуточные результаты ручной коррекции можно сохранять и возобновлять работу позже.

### Сохранение разметки

1. На вкладке Зёрна нажмите Сохранить разметку….
2. В диалоге сохранения выберите формат:
   * TIFF с картой меток — числовое изображение, подходит для программной обработки.
   * ROI ZIP для Fiji — набор ROI-объектов, совместимый со стандартными инструментами Fiji.
3. Укажите путь и имя файла. При необходимости подтвердите перезапись.

Во время сохранения отображается индикатор прогресса. Физический масштаб сохраняется вместе с разметкой.

### Загрузка разметки

1. Убедитесь, что в основном окне загружено исходное изображение того же размера, что и сохранённая разметка.
2. Нажмите Открыть разметку… в панели инструментов.
3. Выберите формат и файл разметки.

При загрузке выполняется валидация:
* Совпадение размеров разметки и изображения.
* Корректность идентификаторов зёрен (целые числа от 0 до 16 777 216).
* Отсутствие пересечений между ROI (для формата ROI ZIP).

Если масштаб в разметке отличается от текущего, будет запрошено подтверждение на его применение.

### Отслеживание изменений

Плагин отслеживает наличие несохранённых изменений в разметке. При попытке закрыть окно, загрузить новый файл или начать новый анализ без сохранения появится диалог подтверждения с вариантами:
* Сохранить и закрыть — сохранить разметку и продолжить операцию.
* Закрыть без сохранения / Закрыть — отменить операцию без сохранения.
* Отмена — вернуться к работе.

## Выделение области интереса

В окне совмещения снимков доступно кадрирование объединённого результата перед передачей в анализ или сохранением.

### Режимы выделения

Переключение между режимами осуществляется выпадающим списком:
* Прямоугольник — выделение прямоугольной области с поддержкой поворота.
* Многоугольник — выделение произвольной замкнутой областью.

### Прямоугольное выделение

1. Нажмите Выделить область.
2. Потяните мышью для создания прямоугольника.
3. Для изменения размера потяните за маркеры на углах и сторонах.
4. Для поворота потяните за круглую ручку над верхней стороной или введите угол в поле Угол, ° (от −180° до 180°).
5. Для перемещения потяните за внутреннюю часть прямоугольника.

### Полигональное выделение

1. Нажмите Выделить область и выберите режим Многоугольник.
2. Кликайте по изображению для добавления вершин.
3. Замкните контур одним из способов:
   * Нажмите Enter.
   * Сделайте двойной клик.
   * Кликните по первой вершине (при наличии минимум трёх вершин).
4. После замыкания:
   * Перетаскивайте вершины для изменения формы.
   * Двойной клик по стороне — вставка новой вершины.
   * Delete — удаление выбранной вершины.
   * Esc — полный сброс выделения.

### Применение выделения

После создания выделения доступны кнопки:
* Сохранить TIFF… — сохранить выделенную область как TIFF-файл. Маска выделения встраивается в файл как область анализа.
* Использовать в Quartz — передать выделенную область в основное окно анализа.

При извлечении применяется билинейная интерполяция (для поворота), физический масштаб переносится из исходного изображения.

### Сброс выделения

Нажмите Сбросить выделение для удаления текущего выделения и возврата к полному снимку.

## Расширенные возможности навигации

Помимо базового масштабирования колесом мыши, интерфейс поддерживает:

* Панорамирование: зажмите среднюю кнопку мыши (колесо) и перемещайте курсор для перемещения изображения.
* Кнопки масштаба: в статусной строке доступны кнопки − и + для пошагового изменения масштаба.
* Слайдер масштаба: ползунок в статусной строке для плавного изменения масштаба.
* Вписать изображение: кнопка в статусной строке для отображения изображения целиком в пределах окна.
* Индикатор масштаба: процентный индикатор в статусной строке (100% соответствует натуральному размеру).

Масштаб и позиция синхронизированы между вкладками Снимок, Карта границ и Зёрна — переключение вкладок сохраняет текущий вид.

## Формат выходных данных

Файл CSV формируется в кодировке UTF-8 без BOM. Разделитель полей — запятая. Первая строка содержит заголовки колонок.

| Колонка | Тип | Единицы | Описание |
|---------|-----|---------|----------|
| `grain_id` | целое | — | Уникальный идентификатор зерна на карте меток. |
| `area_px2` | целое | пиксели² | Площадь зерна, подсчитанная по количеству пикселей. |
| `perimeter_px` | вещественное | пиксели | Периметр, рассчитанный по алгоритму Кротона (4 направления). |
| `equivalent_diameter_px` | вещественное | пиксели | Диаметр окружности равновеликой площади: $2\sqrt{A/\pi}$. |
| `major_axis_px` | вещественное | пиксели | Большая полуось эквивалентного эллипса, умноженная на 2. |
| `minor_axis_px` | вещественное | пиксели | Малая полуось эквивалентного эллипса, умноженная на 2. |
| `aspect_ratio` | вещественное | безразмерная | Отношение большой оси к малой ($\ge 1$). |
| `circularity` | вещественное | безразмерная | $4\pi A / P^2$. Значение 1.0 соответствует идеальному кругу. |
| `roundness` | вещественное | безразмерная | $4A / (\pi \cdot a^2)$, где $a$ — большая полуось. |

## Устранение типичных проблем

### Ошибка: «Для этой модели нужен одиночный RGB-снимок»

Причина: загруженное изображение не соответствует требованиям по формату.
Решение: преобразуйте изображение в 24-бит RGB и убедитесь, что оно не является стеком. В Fiji это можно сделать через `Image › Type › RGB Color`.

### Ошибка: «В выбранной модели нет класса grain_boundary»

Причина: обученная модель Weka не содержит класс с требуемым именем.
Решение: откройте модель в модуле Trainable Weka Segmentation, переименуйте целевой класс границ в `grain_boundary` и сохраните модель повторно.

### Ошибка: «TWS не смог загрузить модель»

Причина: файл модели повреждён, имеет несовместимую версию или не является файлом Weka.
Решение: переобучите модель на актуальной версии Fiji. Убедитесь, что файл имеет расширение `.model` и был сохранён кнопкой *Save model* в интерфейсе TWS.

### Ошибка: «Не удалось открыть одиночное изображение»

Причина: файл повреждён, имеет неподдерживаемый формат или является стеком.
Решение: проверьте файл в Fiji через `File › Open`. Если изображение открывается как стек, извлеките нужный срез через `Image › Stacks › Make Subset`.

### Зёрна не разделяются при проведении линии

Причина: линия не пересекает зерно от края до края, либо пересекает его более чем в двух местах.
Решение: проведите линию заново, начиная и заканчивая строго на границе зерна. Избегайте изломов и возврата линии внутрь зерна.

### Интерфейс реагирует с задержкой на действия пользователя

Причина: изображение имеет высокое разрешение (>4000×4000 px), операции над картой меток выполняются на уровне пиксельных массивов.
Решение: при возможности уменьшайте разрешение изображения до уровня, достаточного для решения задачи (типично 2048×2048 px). Для критичных по производительности случаев рассмотрите предварительное уменьшение изображения через `Image › Scale…`.

### Ошибка: «Не удалось надёжно совместить кадр»

Причина: алгоритм SIFT не нашёл достаточного количества совпадающих признаков между кадрами, либо RANSAC отбросил большинство совпадений как выбросы.
Решение:
* Проверьте порядок кадров — они должны следовать в порядке съёмки с частичным перекрытием.
* Убедитесь, что на всех кадрах изображена одна и та же область образца.
* Удалите кадры с существенными различиями в освещении, фокусе или содержании.
* Проверьте, что все кадры имеют одинаковый размер.

### Ошибка: «Масштабы кадров различаются»

Причина: у добавляемых кадров разный физический масштаб (разный pixel size в метаданных).
Решение: убедитесь, что все кадры получены при одинаковом увеличении микроскопа. При необходимости удалите калибровку с кадров через `Image › Properties…` перед добавлением.

### Ошибка: «Размер разметки не совпадает с размером снимка»

Причина: загруженная разметка (TIFF или ROI ZIP) имеет размеры, отличные от текущего изображения.
Решение: убедитесь, что загружается разметка, созданная для того же изображения. При кадрировании или изменении разрешения снимка разметка становится недействительной.

### Ошибка: «Области ROI пересекаются»

Причина: в ROI ZIP-файле два или более ROI перекрываются, что недопустимо для карты меток.
Решение: файл повреждён или был изменён внешними инструментами. Создайте разметку заново через интерфейс плагина.

### Ошибка: «Выбранная область находится за пределами снимка»

Причина: выделенная область (прямоугольник или многоугольник) полностью находится вне изображения.
Решение: переместите выделение в пределы изображения или сбросьте его кнопкой Сбросить выделение.

### Ошибка: «Размер объединённого снимка слишком велик»

Причина: трансформации кадров приводят к чрезмерно большому размеру общего холста.
Решение: проверьте порядок кадров и корректность регистрации. Возможно, один из кадров был зарегистрирован с ошибкой (большой угол поворота или сдвиг). Удалите проблемный кадр и повторите совмещение.
