# Руководство пользователя. Плагин Quartz Analysis для Fiji

## Назначение

Плагин **Quartz Analysis** предназначен для полуавтоматического морфометрического анализа микроструктурных изображений кварца. Решение выполняет сегментацию границ зёрен, разделяет слипшиеся объекты, позволяет вручную корректировать результаты автоматической обработки и экспортирует геометрические характеристики каждого зерна в формат CSV для дальнейшего статистического анализа.

Документ описывает порядок подготовки входных данных, установки плагина, выполнения анализа и устранения типичных ошибок. Техническое устройство системы изложено в документе [ARCHITECTURE.md](ARCHITECTURE.md).

## Требования к входным данным

### Исходное изображение

Перед запуском анализа убедитесь, что изображение соответствует следующим требованиям:

| Параметр | Требование |
|----------|------------|
| Формат файла | BMP, PNG, TIFF, JPEG |
| Цветовое пространство | RGB (24-бит) |
| Структура | Одиночное 2D-изображение (без Z-стека) |
| Разрешение | Рекомендуется не менее 1024×1024 px для надёжной сегментации |

**Ограничения:**
* Изображения в оттенках серого (8-бит), 16-битные и многоканальные (CFA, гиперспектральные) форматы не поддерживаются.
* Стек изображений (Z-stack) обрабатывается как ошибка валидации. При необходимости анализа нескольких срезов обрабатывайте каждый срез как отдельный файл.

### Модель классификатора Weka

Для сегментации границ требуется предварительно обученная модель, сохранённая в формате `.model`. Модель должна быть обучена в модуле **Trainable Weka Segmentation** среды Fiji.

**Обязательное требование:** в модели должен присутствовать класс с точным именем `grain_boundary` (без кавычек, с символом подчёркивания). Отсутствие данного класса приведёт к ошибке на этапе применения классификатора.

Рекомендуется обучать модель на репрезентативной выборке изображений, аналогичных анализируемым по увеличению, освещению и контрасту.

## Установка плагина

1. Соберите артефакт проекта командой:
   ```bash
   mvn clean package
   ```
2. Скопируйте файл `target/quartz_project-1.0-SNAPSHOT.jar` в директорию `plugins/` вашей локальной установки Fiji.
3. Перезапустите среду Fiji. Плагин появится в меню: `Plugins › Quartz › Analyze Quartz`.

Для проверки корректности установки выполните команду `Plugins › Quartz › Hello Quartz`. В консоль Fiji должно быть выведено сообщение `Hello from Quartz plugin!`.

## Порядок выполнения анализа

### Шаг 1. Запуск интерфейса

Откройте Fiji и выберите в главном меню:

```
Plugins › Quartz › Analyze Quartz
```

Будет открыто главное окно плагина, содержащее три вкладки: **Снимок**, **Карта границ**, **Зёрна**.

### Шаг 2. Загрузка входных данных

Загрузить файлы можно одним из двух способов:

**Способ А. Через кнопки интерфейса:**
* Нажмите **Открыть изображение** и выберите файл снимка.
* Нажмите **Выбрать модель** и укажите путь к файлу `.model`.

**Способ Б. Перетаскиванием (Drag-and-Drop):**
Перетащите файлы изображения и модели непосредственно в окно плагина. Допускается одновременное перетаскивание обоих файлов.

После успешной загрузки в нижней части окна отобразится название изображения и его разрешение, а рядом с кнопкой выбора модели — имя файла модели.

### Шаг 3. Запуск обработки

Убедитесь, что оба файла загружены, и нажмите кнопку **Обработать** в правой части панели инструментов.

Процесс выполняется в два этапа:
1. **Сегментация границ.** Классификатор Weka применяется к изображению и формирует карту вероятностей принадлежности каждого пикселя к классу `grain_boundary`.
2. **Водораздельное преобразование.** Карта вероятностей сглаживается гауссовым фильтром, квантуется и передаётся алгоритму watershed (MorphoLibJ) для разделения слипшихся зёрен и присвоения уникальных идентификаторов.

Во время выполнения интерфейс остаётся отзывчивым. По завершении первого этапа автоматически активируется вкладка **Карта границ**, по завершении второго — вкладка **Зёрна**.

### Шаг 4. Ручная коррекция результатов

Автоматическая сегментация может содержать артефакты: недостаточно разделённые зёрна или, наоборот, ложные границы. Для их устранения предназначен интерактивный редактор на вкладке **Зёрна**.

Подробное описание инструментов коррекции приведено в разделе [Инструменты ручной коррекции](#инструменты-ручной-коррекции).

### Шаг 5. Экспорт данных

После завершения коррекции нажмите **Сохранить CSV…**, укажите путь и имя файла. По умолчанию предлагается имя `measurements.csv`. Если файл с таким именем уже существует, будет запрошено подтверждение на перезапись.

Формат выходного файла описан в разделе [Формат выходных данных](#формат-выходных-данных).

## Инструменты ручной коррекции

На вкладке **Зёрна** доступны следующие операции:

### Выделение зёрен

Кликните левой кнопкой мыши по зерну на изображении. Выбранное зерно подсвечивается оранжевым цветом, его граница отображается более насыщенным оттенком. Под изображением отображаются морфометрические характеристики выбранного зерна: площадь, вытянутость, круглость.

Для снятия выделения кликните по фону (вне зерна).

### Объединение зёрен

Инструмент **Объединить** предназначен для слияния двух соседних зёрен, ошибочно разделённых алгоритмом watershed.

Порядок действий:
1. Убедитесь, что кнопка **Разделить линией** не активна.
2. Кликните по первому зерну — оно будет выделено.
3. Кликните по второму зерну — будут выделены оба.
4. Нажмите **Объединить**. Зёрна будут объединены в одно с сохранением идентификатора первого выбранного зерна.

Объединение возможно только для зёрен, имеющих общую границу. При попытке объединить несоседние зёрна в нижней панели появится сообщение: *«Выбранные зёрна не соседствуют. Выберите другую пару.»*

### Разделение линией

Инструмент **Разделить линией** предназначен для разделения одного зерна, ошибочно объединённого алгоритмом watershed с соседним.

Порядок действий:
1. Нажмите кнопку **Разделить линией** — она перейдёт в активное состояние.
2. Кликните по зерну, которое необходимо разделить. Зерно будет выделено.
3. Зажмите левую кнопку мыши и проведите линию от одного края зерна до другого. Линия должна пересекать зерно полностью, начиная и заканчиваясь на его границе.
4. Отпустите кнопку мыши. Зерно будет разделено на две части.

**Правила разделения:**
* Линия должна делить зерно ровно на две связные области. Если линия не пересекает зерно полностью или разделяет его на три и более частей, операция будет отклонена.
* Меньшая из полученных частей получит новый идентификатор, большая сохранит исходный.
* После успешного разделения инструмент автоматически деактивируется.

### Масштабирование и навигация

* **Масштабирование:** вращение колеса мыши с центром в позиции курсора.
* **Сброс масштаба:** прокрутка до минимального уровня.

## Формат выходных данных

Файл CSV формируется в кодировке UTF-8 без BOM. Разделитель полей — запятая. Первая строка содержит заголовки колонок.

| Колонка | Тип | Единицы | Описание |
|---------|-----|---------|----------|
| `grain_id` | целое | — | Уникальный идентификатор зерна на карте меток. |
| `area_px2` | целое | пиксели² | Площадь зерна, подсчитанная по количеству пикселей. |
| `perimeter_px` | вещественное | пиксели | Периметр, рассчитанный по алгоритму Кротона (4 направления). |
| `equivalent_diameter_px` | вещественное | пиксели | Диаметр окружности равновеликой площади: $2\sqrt{A/\pi}$. |
| `major_axis_px` | вещественное | пиксели | Большая полуось эквивалентного эллипса, умноженная на 2. |
| `minor_axis_px` | вещественное | пиксели | Малая полуось эквивалентного эллипса, умноженная на 2. |
| `aspect_ratio` | вещественное | безразмерная | Отношение большой оси к малой ($\ge 1$). |
| `circularity` | вещественное | безразмерная | $4\pi A / P^2$. Значение 1.0 соответствует идеальному кругу. |
| `roundness` | вещественное | безразмерная | $4A / (\pi \cdot a^2)$, где $a$ — большая полуось. |


## Устранение типичных проблем

### Ошибка: «Для этой модели нужен одиночный RGB-снимок»

**Причина:** загруженное изображение не соответствует требованиям по формату.
**Решение:** преобразуйте изображение в 24-бит RGB и убедитесь, что оно не является стеком. В Fiji это можно сделать через `Image › Type › RGB Color`.

### Ошибка: «В выбранной модели нет класса grain_boundary»

**Причина:** обученная модель Weka не содержит класс с требуемым именем.
**Решение:** откройте модель в модуле Trainable Weka Segmentation, переименуйте целевой класс границ в `grain_boundary` и сохраните модель повторно.

### Ошибка: «TWS не смог загрузить модель»

**Причина:** файл модели повреждён, имеет несовместимую версию или не является файлом Weka.
**Решение:** переобучите модель на актуальной версии Fiji. Убедитесь, что файл имеет расширение `.model` и был сохранён кнопкой *Save model* в интерфейсе TWS.

### Ошибка: «Не удалось открыть одиночное изображение»

**Причина:** файл повреждён, имеет неподдерживаемый формат или является стеком.
**Решение:** проверьте файл в Fiji через `File › Open`. Если изображение открывается как стек, извлеките нужный срез через `Image › Stacks › Make Subset`.

### Зёрна не разделяются при проведении линии

**Причина:** линия не пересекает зерно от края до края, либо пересекает его более чем в двух местах.
**Решение:** проведите линию заново, начиная и заканчивая строго на границе зерна. Избегайте изломов и возврата линии внутрь зерна.

### Интерфейс реагирует с задержкой на действия пользователя

**Причина:** изображение имеет высокое разрешение (>4000×4000 px), операции над картой меток выполняются на уровне пиксельных массивов.
**Решение:** при возможности уменьшайте разрешение изображения до уровня, достаточного для решения задачи (типично 2048×2048 px). Для критичных по производительности случаев рассмотрите предварительное уменьшение изображения через `Image › Scale…`.
